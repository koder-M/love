# 💖 Love Proposal Web Experience

This is a small interactive Valentine’s themed website made with **HTML, CSS, and JavaScript**.  
It’s not just a page — it’s a full emotional flow with videos, jokes, a quiz, photos, and a final message.

I built this as a fun and creative way to express feelings through code.  
Every screen is connected like a story.

---

## 🌸 What’s Inside?

- 🎥 Video based proposal screen  
- 😈 Funny “No” button reactions  
- 🎁 Gift section with surprises  
- 🧠 Cute love quiz  
- 💌 Personal letter screen  
- 📷 Photo gallery  
- ❤️ Final emotional message  

Everything is connected through JavaScript so the flow feels like a mini app.

---

## 🛠️ Tech Used

- **HTML5** – structure  
- **CSS3** – layout, gradients, animations, responsiveness  
- **JavaScript (Vanilla)** – all logic, interactions, page switching  

No frameworks. No libraries. Just clean DOM work.

## 🚀 How to Run

1. Download or clone this project  
2. Make sure the **media folder** is in the same directory  
3. Open `index.html` in your browser  

---

## 🎮 How It Works

- Clicking **No** changes the video and text  
- The **Yes** button grows bigger every time you say No 😆  
- After Yes → you unlock the gifts  
- Gift 1 → Quiz  
- Gift 2 → Letter  
- Gift 3 → Gallery  
- Finally → emotional ending screen  

All screens are handled using `display: none / flex` via JavaScript.
